## 项目目的

M1 中以 parallel run 创建了 `connections` 表，现在 M2 将 MCP 工具的 credential/服务器设置解析路径切换为经由 connection。现有 `mcp_servers` 表 read-only deprecate（M6 drop）。

**M2 完成后**: MCP 工具执行通过 `tool.connection_id → connections → credential/extra_config` 路径工作。直接引用 `mcp_servers` 的路径仅作为 legacy fallback 保留。

## ADR-008 应用规则（必须遵守）

- **extra_config 结构**: `{url, auth_type, headers?, env_vars?, transport?, timeout?}`
- **env_vars 值**: 必须是 `${credential.<field_name>}` 模板（禁止明文）。runtime 解析时替换为 `credential.data_decrypted[<field_name>]`
- **connection.credential_id ON DELETE SET NULL**: 删除 credential 时 connection 仍存在
- **tool.connection_id**: nullable FK。到 M6 前与 `tool.mcp_server_id` 共存
- **legacy fallback**: M6 前，`connection_id IS NULL AND mcp_server_id IS NOT NULL` 的 tool 仍通过现有路径工作（迁移失败 tolerance）
