## ADR-008 核心决定（必须遵守）

- **user_id**：NOT NULL FK `users.id`（权限隔离基础）
- **无 UNIQUE 约束**：仅 UUID PK + user_id FK + index `(user_id, type, provider_name)`
- **type**: VARCHAR(20) `'prebuilt' | 'mcp' | 'custom'`
- **provider_name**: VARCHAR(50). Pydantic validator:
  - `type='prebuilt'`：仅 credential_registry enum（naver, google_search, google_workspace, google_chat, custom_api_key）5 类
  - `type='mcp'` / `type='custom'`：自由字符串（英文/数字/下划线，建议 `^[a-z0-9_]+$`）
- **display_name**：VARCHAR(200) — UI label（允许重复，无 UNIQUE）
- **credential_id**: UUID nullable FK `credentials.id` ON DELETE SET NULL
- **extra_config**：JSON nullable。仅 MCP 使用：
  - `{url, auth_type, headers?, env_vars?, transport?, timeout?}`
  - `url`、`auth_type` 必填（MCP 时）
  - PREBUILT/CUSTOM 为 NULL
- **is_default**：BOOLEAN NOT NULL DEFAULT false。同一 (user_id, type, provider_name) 范围内仅 1 个 True。在 service level 原子切换（自动解除现有 default）
- **status**: VARCHAR(20) NOT NULL DEFAULT 'active' — `'active' | 'disabled'`
- **created_at, updated_at**: TIMESTAMP NOT NULL
- **index**：`(user_id, type, provider_name)`（hot path 查询）

## API 契约（Jensen/贝索斯用）

```
GET    /api/connections                     # 当前用户的 connection 列表（过滤：type, provider_name）
GET    /api/connections/{id}                # 单条查询（user_id 不匹配则 404）
POST   /api/connections                     # 创建（body: ConnectionCreate）
PATCH  /api/connections/{id}                # 修改（body: ConnectionUpdate）
DELETE /api/connections/{id}                # 删除
```

所有 endpoint：必须使用 `get_current_user` + user_id 过滤。
