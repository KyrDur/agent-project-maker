## 📋 System prompt 编写指南

编写 system prompt 时，建议遵循以下结构:

```markdown
# {agent 名称}

## Role（角色）
[用 1-2 句话说明 agent 的目的]

## Responsibilities（主要职责）
[编号的任务列表]

## Tool Guidelines（工具使用指南）
### `{工具名}`
- Purpose: [功能说明]
- When: [何时使用]
- Caution: [注意事项]

## Subagent Guidelines（subagent 指南）
### `{subagent 名称}`
- Expertise: [专业领域]
- Delegate when: [何时委派]

## Workflow（工作流程）
[分步流程说明]

## Constraints（限制事项）
- ALWAYS: [必须做的事]
- NEVER: [绝不能做的事]
```

## 💡 编写技巧

### 1. **Role（角色）**编写
- 明确 agent **做什么**
- 用 1-2 句话简洁说明
- 示例: "这是一个通过互联网搜索收集用户问题所需最新信息，并提供可信回答的 agent。"

### 2. **Responsibilities（职责）**编写
- 列出 agent **需要执行的具体任务**
- 使用编号明确顺序
- 示例:
  ```
  1. 分析用户问题并确定搜索关键词
  2. 使用 tavily_search 工具在互联网上搜索信息
  3. 综合搜索结果并提供清晰回答
  ```

### 3. **Tool Guidelines（工具指南）**编写
- 每个工具包含**3 类信息**:
  - **Purpose**: 工具功能
  - **When**: 何时使用（trigger 条件）
  - **Caution**: 注意事项
- 示例:
  ```
  ### `tavily_search`
  - Purpose: 在互联网上搜索最新信息
  - When: 用户请求信息时、需要最新新闻时
  - Caution: 搜索 query 要明确，优先使用可信来源
  ```

### 4. **Workflow（工作流程）**编写
- 说明**分步流程**
- 明确工具使用顺序
- 示例:
  ```
  1. 分析问题
  2. 执行搜索
  3. 审查结果
  4. 编写回答
  ```

### 5. **Constraints（限制事项）**编写
- **ALWAYS**: 必须遵守的行为
- **NEVER**: 绝不能做的行为
- 示例:
  ```
  - ALWAYS: 仅提供基于搜索结果的信息
  - NEVER: 使用不可信来源
  ```

## 🎯 编写 prompt 时的注意事项

| 项目          | 说明                                     |
| ------------- | ---------------------------------------- |
| **清晰性**    | 避免模糊表达，具体编写                   |
| **结构**      | 明确划分 section，使用层级结构            |
| **工具关联**  | 明确提及 agent 将使用的工具               |
| **明确限制**  | 清楚说明应该做和不应做的事                |
| **包含示例**  | 必要时添加具体示例                        |

## 📌 实际示例

当前创建的"互联网搜索 agent"prompt 遵循这一结构:
- ✅ Role: 通过互联网搜索提供信息
- ✅ Responsibilities: 明确 4 项职责
- ✅ Tool Guidelines: 详细说明 tavily_search 使用方法
- ✅ Workflow: 5 步流程
- ✅ Constraints: ALWAYS/NEVER 规则

可以基于这个模板创建各种 agent！🚀
