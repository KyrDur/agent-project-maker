## 范围与检查方法

仅扫描 Git 跟踪的 UTF-8 文本，不读取个人配置、密钥、依赖目录或生成产物。
使用 `python3 scripts/check_hangul.py --json` 输出文件路径、字符数和行号。
`--check` 在存在残留时返回非零状态，不使用忽略列表隐藏历史迁移。
扫描覆盖现代音节、兼容字母和组合字母。临时仓库验证了行号准确性、
未跟踪文件排除及二进制文件排除。

翻译批次提取 Python 字符串、文档字符串和注释，按完全相同文本去重。
返回文件须覆盖所有 ID，保留英文标识、换行和代码结构；所有文件通过语法
解析后才写入。运行文案变化须同步检查测试输入及识别逻辑。
历史实验、用户理由和冻结证据不属于源码翻译范围，不能重写为新实验。
