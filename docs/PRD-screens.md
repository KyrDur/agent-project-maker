### 7. 页面构成

#### 7.1 页面列表

| 页面名称 | 说明 | 进入路径 |
|--------|------|----------|
| 仪表盘 | 我的 Agent 列表 + 使用量汇总 | /（主页） |
| 创建 Agent — 方式选择 | 通过对话 / 模板创建 | 仪表盘 → [+ 新建 Agent] |
| 创建 Agent — 对话式 | 与 AI 对话并配置 Agent | 方式选择 → 通过对话创建 |
| 创建 Agent — 模板 | 浏览并选择模板 | 方式选择 → 通过模板创建 |
| Agent 聊天 | 与 Agent 对话 | 仪表盘 → 点击 Agent 卡片 |
| Agent 设置 | 修改名称、prompt、工具、模型 | 聊天 → 设置图标 |
| 工具管理 | 工具列表、注册 MCP/自定义工具 | 侧边栏 → 工具管理 |
| 模型管理 | 模型列表、注册自定义模型 | 侧边栏 → 模型管理 |
| 使用量仪表盘 | 按 Agent 查看 token·费用 | 侧边栏 → 使用量 |

#### 7.2 页面流程图

```
[仪表盘] ──[+ 新建 Agent]──> [方式选择]
   │                              ├──> [对话式创建] ──确认──> [聊天]
   │                              └──> [模板选择] ──创建──> [聊天]
   │
   ├──[Agent 卡片]──> [聊天] ──[设置]──> [Agent 设置]
   ├──[侧边栏：工具]──> [工具管理] ──[+ 添加]──> [MCP Server / 直接定义]
   ├──[侧边栏：模型]──> [模型管理]
   └──[侧边栏：使用量]──> [使用量仪表盘]
```
